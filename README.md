# Scrim

A Chromium extension that hides whole **topics** (AI, work, software/IT, NSFW, or your own)
across feeds, blocks sites per profile, and tames YouTube.

> Work in progress. See `docs/superpowers/specs/2026-10-17-scrim-design.md`.

## Development

```bash
pnpm install
pnpm dev        # launches Chrome with the extension loaded
pnpm test
pnpm build      # outputs .output/chrome-mv3 (Load unpacked)
```
